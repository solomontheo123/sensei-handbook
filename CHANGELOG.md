- Knowledge increases.

---

# Versioning

The handbook follows a simple versioning approach.

Example:

```
v1.0.0
```

Meaning:

```
Major.Minor.Patch
```

---

# Version Guidelines

## Major Version

Used for:

- Complete restructuring.
- Major philosophy changes.
- Significant handbook redesign.

Example:

```
v2.0.0
```

---

## Minor Version

Used for:

- Adding new documents.
- Adding major sections.
- Expanding existing knowledge.

Example:

```
v1.1.0
```

---

## Patch Version

Used for:

- Fixing mistakes.
- Improving wording.
- Small corrections.

Example:

```
v1.0.1
```

---

# Change Categories

Changes are grouped into:

## Added

New content or documents.

Example:

```
Added ARCHITECTURE.md
```

---

## Changed

Existing content improved.

Example:

```
Updated React architecture guidelines.
```

---

## Fixed

Errors corrected.

Example:

```
Fixed incorrect TypeScript examples.
```

---

## Removed

Deprecated content removed.

Example:

```
Removed outdated workflow.
```
